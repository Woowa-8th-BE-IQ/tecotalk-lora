# 발표 메시지와 시나리오

## 제목

**LoRA로 보는 파인튜닝과 학습의 원리**

오프닝 한 줄: "모델의 main 브랜치는 건드리지 않습니다. 패치만 붙입니다."

## 청중이 나가면서 말할 수 있어야 할 것

1. 학습은 **손실이 줄어드는 방향으로 가중치를 조금씩 고치는 것**이다.
2. 그 방향은 **편미분**으로 구한다. 하나만 남기고 고정해 미분하고, 방향별 기울기를 모아 **반대로** 걷는다.
3. 고칠 양 ΔW는 거대한 행렬인데, **LoRA는 이를 작은 행렬 두 개(B × A)로 표현해서 학습한다.** 원본 W는 그대로 둔다.

이 셋에 안 걸리는 내용은 본편에서 뺀다.

## 흐름 (6단계 구조)

발표 준비 피드백으로 받은 구조: **배경 맞추기 → 문제 체감 → 해결 방향 → 전체 그림 → 세부 → 회수와 확장.**
현재 본편은 이 중 앞쪽 세 단계를 영상 4개로 압축했다.

### 1부. 최적값은 어떻게 찾나 (영상 1, 2)

- **저차원에서 시작해 차원을 넓힌다.** 가중치 1개 → 2개(곡면) → 70억 개.
- 3D 곡면 z = f(x, y)에서 **x, y = 가중치, z = 손실**로 읽는다.
- "기울기(gradient)"를 바로 꺼내지 않는다. **편미분부터** 보여준다.
  - y를 고정하면 곡면이 곡선으로 잘린다 → 그 곡선을 x로 미분 = ∂z/∂x.
  - 고정값이 바뀌면 단면도 기울기도 바뀐다. 그래도 방법은 같다.
  - 점 근처는 평평한 판처럼 보인다 → 방향별 변화를 더하면 아무 방향의 변화가 된다.
- 방향별 기울기를 모은 화살표의 **반대**로 걸으면 내려간다. 걸음 크기 = 학습률 η.
- 영상 2(나침반)에서 같은 내용을 **느낌으로** 다시 보여준다: 공이 굴러 내려가고, 바닥에선 나침반이 회색이 되어 멈춘다. 출발점이 다르면 다른 골짜기에 멈출 수 있다.

### 2부. 그 높이는 손실이다 (선택 영상 + 영상 3 앞부분)

- LLM의 손실 = −log(정답 단어에 준 확률). 수천 문장의 평균 → 숫자 하나.
- "가중치 70억 개를 넣으면 손실 1개가 나오는 함수"를 줄이는 게 학습.
- 우리가 실제로 구하는 것은 **ΔW** (가중치를 얼마나 바꿀지).

### 3부. LoRA: 그 계산을 작게 (영상 3 뒷부분, 영상 4)

- 가중치는 큰 표(행렬)로 저장된다. ΔW도 같은 모양. 실제로는 4096 × 4096 = 1,677만 칸, 모델 전체 약 70억 칸.
- 질문: "이 큰 ΔW를 작은 행렬 두 개로 표현할 수 없을까?"
- 구구단표: 25칸이 숫자 10개로 만들어진다 (rank 1). 모든 행이 같은 모양, 크기만 다르다.
- 패턴을 겹치면 rank 2, 3, … → B × A = 패턴 r개를 겹친 것.
- 실제 파인튜닝의 ΔW는 **센 패턴 몇 개에 몰려 있다** (LoRA의 가정). 그래서 r이 작아도 거의 같다.
- 학습: B = 0에서 시작(처음엔 원본 그대로) → 경사하강으로 **B, A만** 고친다. W는 고정.
- 끝나면 W + BA로 합쳐서 추론 속도 손해가 없다.
